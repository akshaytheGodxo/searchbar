**Better Search**
Welcome to Better Search, a window utility tool for doing quick file and folder searches of any kind.

Tools used in this project: 
- [x] **ImGui** : https://github.com/ocornut/imgui
- [x] **nlohmann/json** : http://nlohmann.github.io/json/
- [x] **SQLite** : https://www.sqlite.org/index.html
- [x] Visual Studio 2022 : https://visualstudio.microsoft.com/
